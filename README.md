# Portfolio

Personal portfolio showcasing projects across development, cybersecurity, and blockchain.

## Tech Stack

- Next.js
- Tailwind CSS
- Supabase

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Features

- Project showcase filtered by domain and subcategory
- Domain-specific resumes
- Contact section
- Admin panel for managing content
